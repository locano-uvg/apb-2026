Ciclo FOR

El ciclo for repite un bloque de código un número definido de veces. En Python se usa para recorrer secuencias: listas, cadenas o rangos numéricos.

Sintaxis

python 
for variable in secuencia:
    # instrucciones (indentadas con 4 espacios)
    # se repiten por cada elemento de la secuencia

Ejemplos

Recorrer un rango numérico

for i in range(5):
    print(i)

# Imprime: 0 1 2 3 4

Acumular valores

suma = 0
for i in range(1, 6):
    suma += i
print(suma)  # 15

Recorrer una cadena

for letra in "hola":
    print(letra)

# Imprime: h  o  l  a

Calcular factorial

fact = 1
for i in range(1, 6):
    fact *= i
print(fact)  # 120
💡
La variable del for (i, j, x, letra…) toma automáticamente cada valor de la secuencia. No necesitas actualizarla manualmente.
2

La función range()

La función range() genera una secuencia de números enteros. Puede recibir 1, 2 o 3 argumentos. El límite superior nunca se incluye.

Forma Genera Ejemplo Resultado
range(fin) Del 0 hasta fin − 1 range(5) 0, 1, 2, 3, 4
range(inicio, fin) Del inicio hasta fin − 1 range(2, 6) 2, 3, 4, 5
range(inicio, fin, paso) Saltos de 'paso' range(0, 10, 3) 0, 3, 6, 9
range(inicio, fin, -n) Cuenta regresiva range(5, 0, -1) 5, 4, 3, 2, 1

Paso positivo (ascendente)

for i in range(0, 10, 2):
    print(i)
# 0  2  4  6  8

Paso negativo (descendente)

for i in range(10, 0, -2):
    print(i)
# 10  8  6  4  2
⚠️
Si el paso es 0, Python lanza un ValueError. Para contar hacia atrás, el inicio debe ser mayor que el fin y el paso debe ser negativo.

Ciclo WHILE

El ciclo while repite un bloque de código mientras una condición sea verdadera. A diferencia del for, no itera sobre una secuencia: repite hasta que la condición cambie.

Sintaxis

while condicion:
    # instrucciones
    # IMPORTANTE: algo dentro debe cambiar la condición
    # para que eventualmente sea False

Ejemplos

Contador básico

i = 1
while i <= 5:
    print(i)
    i += 1  # actualizar

# Imprime: 1 2 3 4 5

Suma acumulada

total = 0
num = 1
while num <= 10:
    total += num
    num += 1
print(total)  # 55

División sucesiva

n = 100
while n > 1:
    n //= 2
    print(n)

# 50  25  12  6  3  1

Con break

i = 0
while True:
    if i >= 3:
        break
    print(i)
    i += 1
# 0  1  2
⚠️
Ciclo infinito: si no actualizas la variable de la condición dentro del while, el ciclo nunca termina. En Python puedes detenerlo con Ctrl + C.

Ciclos anidados

Un ciclo anidado es un ciclo dentro de otro. Por cada iteración del ciclo externo, el ciclo interno se ejecuta completo.

Estructura básica

for i in range(3):      # externo
    for j in range(2):  # interno
        print(i, j)

# (0,0) (0,1)
# (1,0) (1,1)
# (2,0) (2,1)
# Total: 3 × 2 = 6 prints

Triángulo de asteriscos

for i in range(1, 5):
    for j in range(i):
        print("*", end="")
    print()

# *
# **
# ***
# ****
💡
El número total de ejecuciones del cuerpo interior es el producto de las iteraciones de cada ciclo. Ejemplo: range(4) × range(3) = 12 ejecuciones.

Errores comunes

Ciclo infinito en while Olvidar actualizar la variable de la condición 
# ❌ Ciclo infinito — x nunca cambia
x = 0
while x < 5:
    print(x)        # se ejecuta infinitamente

# ✅ Correcto
x = 0
while x < 5:
    print(x)
    x += 1          # actualizar aquí
range() no incluye el límite superior range(1, 10) genera del 1 al 9, no incluye el 10 
# ❌ Suma solo hasta 9 → resultado: 45
suma = 0
for i in range(1, 10):
    suma += i

# ✅ Suma hasta 10 → resultado: 55
suma = 0
for i in range(1, 11):  # 11 para incluir el 10
    suma += i
Acumulador inicializado en 0 para multiplicar Inicializar en 0 con *= siempre da 0 
# ❌ Siempre imprime 0
prod = 0          # error: inicializar en 0
for i in range(1, 6):
    prod *= i

# ✅ Correcto → 120
prod = 1          # neutro multiplicativo = 1
for i in range(1, 6):
    prod *= i
Paso negativo sin invertir inicio y fin Para descender, inicio debe ser mayor que fin 
# ❌ No genera nada (rango vacío)
for i in range(1, 10, -1):
    print(i)

# ✅ Cuenta regresiva del 10 al 1
for i in range(10, 0, -1):
    print(i)

FOR vs WHILE — ¿cuándo usar cada uno?

Criterio Ciclo FOR Ciclo WHILE
Número de iteraciones Conocido de antemano Puede no conocerse
Condición de parada Se agota la secuencia Condición booleana
Actualización de variable Automática (Python la hace) Manual (debes hacerlo tú)
Riesgo de ciclo infinito No Sí, si olvidas actualizar
Caso típico Listas, tablas, rangos fijos Leer hasta condición, juegos, reintentos
💡
Regla práctica: si puedes escribir el número de iteraciones antes de correr el programa, usa for. Si dependes de que algo cambie durante la ejecución, usa while.
