Parcial en Línea

Complete sus datos y lea las instrucciones antes de iniciar. El parcial consta de tres secciones: selección múltiple, preguntas directas y análisis de código.

Instrucciones generales

  • Tiempo total: 90 minutos. El parcial se enviará automáticamente al agotarse el tiempo.
  • Sección I — Selección múltiple (15 pts): Seleccione la respuesta correcta para cada pregunta.
  • Sección II — Preguntas directas (15 pts): Escriba el código Python solicitado en cada espacio de respuesta.
  • Sección III — Análisis de código (20 pts): Lea el código, explique qué hace, identifique el error y escriba la versión corregida.
  • Puede navegar entre secciones y modificar sus respuestas antes de enviar el parcial.
  • No se muestra retroalimentación durante el examen. El docente calificará las respuestas abiertas.
