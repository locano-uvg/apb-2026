Definición

Una lista es una estructura que almacena una colección de elementos ordenados. Cada elemento tiene un índice asociado que comienza en 0.

A diferencia de las cadenas, las listas son mutables: es posible modificar, agregar o eliminar elementos directamente. Se definen con corchetes [].

📋
Una lista homogénea contiene elementos del mismo tipo. Una lista heterogénea mezcla distintos tipos de datos.

Listas básicas

lista = [1, 2, 3]
lista_vacia = []

print(lista)        # [1, 2, 3]
print(lista_vacia)  # []

Homogéneas y heterogéneas

homogenea1 = [1, 2, 3]
homogenea2 = ["a", "e", "i", "o", "u"]
homogenea3 = [3.14, 3.15, 3.16]
homogenea4 = [True, False]

heterogenea = [1, "a", 3.14, True]

Operaciones básicas

Las listas soportan las mismas operaciones de acceso por índice, slicing, concatenación y repetición que las cadenas, con la ventaja de ser mutables.

len() y acceso por índice

lista = [2, 2, 3, 4, 5, 6]

print(len(lista))   # 6
print(lista[0])   # 2
print(lista[-1])  # 6

Concatenación (+) y repetición (*) 

a = [1, 2, 3]
b = [4, 5]

print(a + b)   # [1, 2, 3, 4, 5]
print([0] * 4) # [0, 0, 0, 0]

Slicing

lista = [2, 2, 3, 4, 5, 6]

sub = lista[1:3]
print(sub)   # [2, 3]

Modificar elemento por índice

lista = [2, 2, 3, 4]

lista[0] = 1

print(lista)  # [1, 2, 3, 4]
💡
La asignación por slice permite reemplazar varios elementos a la vez: lista[1:4] = [8, 9, 10]

Métodos

Las listas tienen métodos integrados. A diferencia de los métodos de cadena, muchos de estos modifican la lista original en lugar de retornar una nueva. Referencia completa: docs.python.org.

Método / Función ¿Qué hace? Modifica original
len(lista) Número de elementos No
.append(x) Agrega x al final Sí
.insert(i, x) Inserta x en posición i Sí
.remove(x) Elimina la primera aparición de x Sí
.pop() Elimina y retorna el último elemento Sí
del lista[i] Elimina elemento en índice i Sí
.clear() Vacía la lista Sí
.sort() Ordena ascendente Sí
.sort(reverse=True) Ordena descendente Sí
.extend(lista2) Agrega todos los elementos de lista2 Sí
.index(x) Índice de la primera aparición de x No
list(cadena) Convierte cadena a lista de caracteres No
cadena.split(sep) Divide cadena en lista por separador No
sep.join(lista) Une lista en cadena con separador No

Agregar y eliminar elementos

.append()
lista = [1, 2, 3]
lista.append(4)
print(lista)  # [1, 2, 3, 4]
.insert(i, x)
lista = [1, 2, 3]

Cadenas ↔ Listas

list() — cadena a lista
cadena = "Hello"
nueva = list(cadena)
print(nueva)
# ['H', 'e', 'l', 'l', 'o']
.split() y .join()

print(palabras)
# ['Hola', 'Mundo', 'Python']

unido = " ".join(palabras)
print(unido)
# Hola Mundo Python

Recorrer listas

Las listas son iterables: se pueden recorrer elemento por elemento con for o con while usando índice.

Con for (sin índice)

lista = ["uno", "dos", "tres"]

for elemento in lista:
    print(elemento)

# uno
# dos
# tres

Con while (usando índice)

lista = ["uno", "dos", "tres"]
indice = 0

while indice < len(lista):
    print(lista[indice])
    indice += 1
💡
Usa for cuando solo necesitas el valor. Usa while con índice cuando también necesitas la posición del elemento mientras iteras.

Definición

Un diccionario es una estructura de datos que almacena pares llave: valor. También se conocen como matrices asociativas. Se definen con llaves {}.

Los diccionarios son mutables — se pueden modificar sus valores. Sin embargo, las llaves son inmutables: una vez definidas no pueden cambiar.

🔑
Cada llave actúa como un identificador único del valor, de forma más "natural" que un índice numérico. Las llaves deben ser únicas dentro del mismo diccionario.

Crear un diccionario

diccionario = {
    "codigo": "cc2005",
    "nombre": "Algoritmos",
    "creditos": 6
}

print(diccionario)
print(diccionario["codigo"])
# cc2005

Valor de tipo lista

diccionario = {
    "carnet": "123456",
    "notas": [100, 90, 80, 100]
}

print(diccionario["notas"])
# [100, 90, 80, 100]
2

Modificar, agregar y eliminar

Modificar un valor existente

dic = {
    "codigo": "cc2005",
    "creditos": 6
}

dic["creditos"] = 4

print(dic)
# {'codigo': 'cc2005', 'creditos': 4}

Agregar una nueva llave

dic = {
    "codigo": "cc2005",
    "creditos": 6
}

dic["catedratico"] = "Ludwing Cano"

print(dic)
# {'codigo': 'cc2005', 'creditos': 6,
#  'catedratico': 'Ludwing Cano'}

Eliminar con del

dic = {
    "codigo": "cc2005",
    "nombre": "Algoritmos",
    "creditos": 6
}

del dic["creditos"]

print(dic)
# {'codigo': 'cc2005', 'nombre': 'Algoritmos'}

Verificar si existe una llave

dic = {"nombre": "Ana", "edad": 20}

print("nombre" in dic)   # True
print("seccion" in dic)  # False
3

Métodos

Los diccionarios tienen métodos para acceder a sus llaves, valores y combinar diccionarios. Referencia completa: docs.python.org.

Método ¿Qué hace? Ejemplo
dic["llave"] Accede al valor (lanza error si no existe) dic["codigo"]
.get(llave) Accede al valor (retorna None si no existe) dic.get("codigo")
.get(llave, default) Retorna default si la llave no existe dic.get("seccion", -1)
.keys() Retorna todas las llaves del diccionario dic.keys()
.values() Retorna todos los valores del diccionario dic.values()
.update(dic2) Combina dic2 en el diccionario actual dic.update(dic2)

Acceso a valores

.get() y .get() con default 
dic = {
    "codigo": "cc2005",
    "creditos": 6
}

print(dic.get("codigo"))      # cc2005
print(dic.get("seccion", -1)) # -1
.keys() y .values()
dic = {"codigo": "cc2005", "creditos": 6}

llaves = list(dic.keys())
valores = list(dic.values())

print(llaves)   # ['codigo', 'creditos']
print(valores)  # ['cc2005', 6]

Combinar diccionarios

.update()
dic = {
    "codigo": "cc2005",
    "creditos": 6
}
dic2 = {
    "seccion": 600,
    "catedratico": "Ludwing Cano"
}

dic.update(dic2)

print(dic)
# {'codigo': 'cc2005', 'creditos': 6,
#  'seccion': 600, 'catedratico': 'Ludwing Cano'}
💡
Prefiere .get() sobre el acceso directo dic["llave"] cuando no estés seguro de si la llave existe — evita errores en tiempo de ejecución.

Errores comunes

Acceder a una llave que no existe KeyError si la llave no está en el diccionario 
# ❌ KeyError: 'seccion'
dic = {"codigo": "cc2005", "creditos": 6}
print(dic["seccion"])

# ✅ Correcto: usar .get() con valor por defecto
print(dic.get("seccion", "No disponible"))
# No disponible

# ✅ O verificar con in antes de acceder
if "seccion" in dic:
    print(dic["seccion"])
Confundir append() con agregar una llave Los diccionarios no tienen .append() — se asigna directamente 
# ❌ AttributeError: 'dict' object has no attribute 'append'
dic = {"nombre": "Ana"}
dic.append("edad", 20)

# ✅ Correcto: asignar una nueva llave directamente
dic["edad"] = 20
print(dic)  # {'nombre': 'Ana', 'edad': 20}
Usar una llave mutable (como lista) como llave Las llaves deben ser inmutables → TypeError 
# ❌ TypeError: unhashable type: 'list'
dic = {[1, 2]: "valor"}

# ✅ Correcto: usar tipos inmutables como llave
dic = {(1, 2): "valor"}   # tuple como llave
dic = {"clave": "valor"}   # string como llave
