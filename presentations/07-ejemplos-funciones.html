Definición y ventajas

Una función es un bloque de código que se puede invocar para realizar una tarea específica. Es una forma eficiente de realizar tareas repetitivas y ayuda a disminuir la cantidad de código a programar.

Ventaja ¿Por qué importa?
Reduce repetición de código Escribes la lógica una vez y la usas cuantas veces necesites.
Mejora legibilidad Un nombre descriptivo explica qué hace el bloque sin leerlo línea por línea.
Facilita el mantenimiento Si algo cambia, solo modificas la función, no cada lugar donde se usó.
Permite reutilización La misma función puede usarse en distintos programas o contextos.
💡
Piensa en una función como una receta: la escribes una vez y la sigues cada vez que necesitas el mismo resultado, sin repetir los pasos.
2

Crear funciones

Para definir una función en Python se usa la palabra reservada def, seguida del nombre de la función y paréntesis. El cuerpo va indentado con 4 espacios.

Sintaxis

python 
def nombre_funcion():
    # instrucciones (indentadas con 4 espacios)
    # se ejecutan cada vez que se llama la función

Ejemplos

Función sin parámetros

def saludar():
    print("Hola mundo")

saludar()  # Hola mundo

Reutilizar la misma función

def saludar():
    print("Hola mundo")

saludar()
saludar()
saludar()
# Imprime 3 veces "Hola mundo"
ℹ️
Definir ≠ ejecutar. Escribir def saludar(): solo crea la función. Para que corra debes llamarla: saludar().
3

Parámetros

Un parámetro es una variable declarada en la definición de la función que sirve para recibir valores de entrada cuando la función es llamada. Hacen las funciones flexibles y reutilizables.

Ejemplos

Un parámetro

def saludar(nombre):
    print(f"Hola {nombre}")

saludar("Ana")   # Hola Ana
saludar("Luis")  # Hola Luis

Dos parámetros

def suma(a, b):
    print(a + b)

suma(3, 4)   # 7
suma(10, 5)  # 15

Tres parámetros — promedio

def promedio(n1, n2, n3):
    total = n1 + n2 + n3
    print(total / 3)

promedio(5, 10, 7)  # 7.333…

Parámetro con operación

def doble(numero):
    print(numero * 2)

doble(7)   # 14
doble(15)  # 30
💡
Los parámetros se declaran dentro de los paréntesis al definir la función. Los valores concretos que envías al llamarla se llaman argumentos.
4

Retorno de valores

El retorno es el valor que la función devuelve al terminar su ejecución. Se indica con la palabra reservada return. Una función puede retornar cualquier tipo de dato, o no retornar nada.

Sintaxis

python 
def nombre(parametros):
    # instrucciones
    return resultado   # devuelve el valor al que llamó la función

Ejemplos

Retornar un número

def cuadrado(x):
    return x * x

resultado = cuadrado(5)
print(resultado)  # 25

Celsius a Fahrenheit

def celsius_a_fahrenheit(c):
    return (c * 9/5) + 32

print(celsius_a_fahrenheit(25))
# 77.0

Promedio con return

def promedio(n1, n2, n3):
    total = n1 + n2 + n3
    return total / 3

p = promedio(5, 10, 7)
print(p)  # 7.333…

print vs return

# Solo imprime — no guarda nada
def f1(x):
    print(x * 2)

# Retorna — puedes usar el valor
def f2(x):
    return x * 2

a = f2(5) + 10  # a = 20
⚠️
Cuando una función no tiene return, Python devuelve None automáticamente. Si intentas usar ese valor en una operación obtendrás un error.

Alcance (Scope)

Los parámetros y variables declaradas dentro de una función solo existen ahí. No se pueden acceder desde fuera. Esto se llama alcance local.

Variable local (no accesible fuera)

def suma(a, b):
    resultado = a + b
    return resultado

print(suma(3, 4))  # 7

# ❌ Esto genera NameError:
# print(resultado)

Cada llamada tiene su propio scope

def cuadrado(x):
    potencia = x ** 2
    return potencia

print(cuadrado(3))  # 9
print(cuadrado(5))  # 25
# 'potencia' no existe aquí
💡
Piensa en el scope de una función como una caja sellada: lo que está dentro no se ve desde fuera, y cada vez que la llamas se crea una caja nueva independiente.
6

Parámetros por defecto

Un parámetro por defecto tiene un valor predeterminado que se usa cuando el argumento no es proporcionado al llamar la función.

Sintaxis

python 
def nombre(parametro=valor_por_defecto):
    # instrucciones

Ejemplos

Un parámetro con defecto

def saludar(nombre="invitado"):
    print(f"Hola {nombre}")

saludar()         # Hola invitado
saludar("Luis")   # Hola Luis

Combinar obligatorio y defecto

def potencia(base, exponente=2):
    return base ** exponente

print(potencia(3))      # 9  (3²)
print(potencia(2, 10))  # 1024
⚠️
Los parámetros con valor por defecto deben ir después de los parámetros obligatorios, o Python lanzará un SyntaxError.

Errores comunes

Olvidar return La función retorna None sin avisar 
# ❌ No retorna nada → resultado es None
def cuadrado(x):
    x * x         # calcula pero no retorna

resultado = cuadrado(5)
print(resultado)  # None

# ✅ Correcto
def cuadrado(x):
    return x * x

print(cuadrado(5))  # 25
Llamar la función antes de definirla Python ejecuta de arriba a abajo 
# ❌ NameError: 'saludar' no está definida aún
saludar()

def saludar():
    print("Hola")

# ✅ Correcto: definir primero, llamar después
def saludar():
    print("Hola")

saludar()
Número incorrecto de argumentos Debes enviar exactamente los argumentos que la función espera 
def suma(a, b):
    return a + b

# ❌ TypeError: falta un argumento
suma(5)

# ❌ TypeError: demasiados argumentos
suma(1, 2, 3)

# ✅ Correcto
suma(5, 3)  # 8
Acceder a variable local fuera de la función Las variables locales solo existen dentro de la función 
def calcular():
    valor = 42
    return valor

calcular()

# ❌ NameError: 'valor' no está definida aquí
# print(valor)

# ✅ Usar el valor retornado
resultado = calcular()
print(resultado)  # 42

Buenas prácticas

Práctica Descripción
Nombres descriptivos calcular_area() es mejor que ca() o funcion1().
Una tarea por función Cada función debe hacer una sola cosa bien definida.
Pocos parámetros Más de 3-4 parámetros es señal de que la función hace demasiado.
Docstrings Una línea entre comillas triples describe qué hace la función.

Ejemplos

Con docstring

def area_circulo(radio):
    """Calcula el área de un círculo."""
    return 3.14159 * radio ** 2

print(area_circulo(5))  # 78.53…

Nombre descriptivo vs. genérico

# ❌ Nombre poco descriptivo
def f(x, y):
    return x + y

# ✅ Nombre claro
def sumar_enteros(a, b):
    return a + b
⭐
Regla práctica: si necesitas un comentario para explicar qué hace una función, probablemente su nombre no es suficientemente descriptivo. Mejora el nombre primero; agrega el docstring para el cómo y el por qué.
